# StageReady

StageReady is a pre-show readiness management SaaS application for small production houses. It helps Production Managers and crew coordinate departmental checklists, production members and contacts, in-house equipment, external rentals, technical issues and final readiness approval.

This repository contains a solo project for CSCI3100 Software Engineering.

## Planned Technology

- Ruby 3.3.8
- Ruby on Rails 8.0
- PostgreSQL
- RSpec
- Cucumber
- SimpleCov
- GitHub Actions

## Project Status

Planning and proposal stage.

## Disclaimer

StageReady is a course demonstration and is not an official production-management service. All demonstration organizations, productions, contacts and equipment records are synthetic.
